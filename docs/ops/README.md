# Tenant Onboarding Docs

Two documents live here — one for **your team** and one you'll send to
**every new restaurant** (the tenant).

| Doc                             | Audience                         | Purpose                              |
| ------------------------------- | -------------------------------- | ------------------------------------ |
| `PLATFORM_ARCHITECTURE.md`      | Anyone new to the platform       | Hub-and-spoke architecture, all apps + integrations |
| `TENANT_ONBOARDING_OPS.md`      | Suparna Dey Platform ops team    | Step-by-step technical runbook       |
| `TENANT_INTAKE_FORM.md`         | Prospective / new tenants        | Info you need to collect from them   |
| `TENANT_ACCEPTANCE_TESTS.md`    | Ops team, run per tenant         | 199-case checklist run before flipping tenant to LIVE |

PDFs live in [`./pdf/`](./pdf/) and are regenerated by:

```bash
python scripts/build_docs.py           # build all
python scripts/build_docs.py --file TENANT_INTAKE_FORM.md  # build one
```

## Downloading the PDFs

Once this repo is pushed to GitHub, share these direct links (raw
download):

```
https://github.com/<ORG>/<REPO>/raw/main/docs/ops/pdf/TENANT_ONBOARDING_OPS.pdf
https://github.com/<ORG>/<REPO>/raw/main/docs/ops/pdf/TENANT_INTAKE_FORM.pdf
```

Or from a clone:

```bash
open docs/ops/pdf/TENANT_INTAKE_FORM.pdf
```

## Editing the docs

Only edit the `.md` files. Never hand-edit the PDFs — they'll be
regenerated on every build and your edits will be lost. After changing
Markdown, re-run `python scripts/build_docs.py` and commit **both** the
`.md` and the regenerated `.pdf`.

## Styling

Fonts, colors, page margins, and the "Suparna Dey Platform" header line
live at the top of `scripts/build_docs.py`. Tweak the `CSS_TEMPLATE`
constant to change the look.
